# 개선 계획

현재 구현과 아직 구현하지 않은 기능을 구분합니다. 체크되지 않은 항목은 제공 중인 기능이 아닙니다.

## 현재 구현

- [x] 4개 해역, 41개 지점 선택과 전체 바로가기
- [x] 모의 조석 카드, 24시간 곡선, 7일 시각표
- [x] KST 기준 오늘·시각 처리, 선택 날짜 유지
- [x] 라이트·다크 테마와 반응형 화면
- [x] 모의 데이터 및 MCP 진단의 범위 표시
- [x] README, 구조 문서, 기여 안내, 이슈·PR 양식
- [x] Node.js 회귀 검사와 GitHub Actions

## 우선순위 1 · 실제 데이터 기반 마련

- [ ] 국립해양조사원 등 공식 데이터 제공 API의 이용 조건과 지점 코드 확인
- [ ] 서버 계층에서 키 관리·요청 제한·캐시 처리
- [ ] 출처·갱신 시각·관측/예측 구분·단위·조위 기준면을 포함한 공통 데이터 구조 정의
- [ ] 실측 데이터와 데모 모드 전환, 오류·미수신 상태 명시
- [ ] 대표 지점·날짜의 공식 자료와 비교하는 정확도 검증

완료 기준: 실제 출처와 시각을 확인할 수 있고, API 오류가 실제 관측값으로 위장한 모의 값으로 바뀌지 않아야 합니다.

## 우선순위 2 · MCP와 날짜 정확성

- [ ] 표준 클라이언트로 초기화·버전 협상·인증·세션·필요한 전송 방식 구현
- [ ] 서버에서 확인한 도구 스키마에 따라 실제 `tools/call` 연결
- [ ] 결과를 대시보드 데이터 구조로 변환하고 실패 상태 처리
- [ ] 검증된 음력 변환과 지역별 물때 규칙 적용
- [ ] 날짜 경계에서의 이벤트 소속일과 조위 곡선 일치 검증

## 우선순위 3 · 운영 품질

- [ ] Tailwind Play CDN을 빌드 결과물로 교체하고 외부 의존성 버전 고정
- [ ] 관측소·날짜·테마의 URL 공유 또는 저장
- [ ] 모달 키보드 탐색·포커스 복귀와 표·그래프 접근성 개선
- [ ] 모바일·데스크톱 브라우저 검사 자동화
- [ ] 저장소 소유자가 배포·재사용 라이선스 결정
